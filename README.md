# CIN Discord Convocation Updater

GitHub Actions aggiorna la convocazione Discord ogni 10 minuti, senza PC acceso.

## Configurazione GitHub

1. Crea un repository **pubblico** e carica questa cartella.
2. In **Settings → Secrets and variables → Actions**, crea il secret `DISCORD_TOKEN` con il token corrente del bot.
3. In **Actions**, esegui una volta il workflow **Aggiorna convocazione Discord** con **Run workflow**.

Il repository non contiene token, fogli Google o elenco degli iscritti.
